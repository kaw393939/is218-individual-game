# Research roadmap

**Current phase: research & planning.** Next, choose one mechanic to investigate and complete the [game brief](./game-brief.md).

| Stage | Next action | Done when |
| --- | --- | --- |
| Establish evidence | Read the [REA findings](../research/rea-game-reconstruction.md) and [sources](../research/sources.md) | Initial docs and static game inspections are recorded; complete |
| Define the game | Fill in the [brief](./game-brief.md) | Player, platform, core loop, scope, time, and budget are clear |
| Compare approaches | Run planning experiments [E01 and E04](./experiments.md) | Engine comparison and reviewed design support a choice |
| Record decisions | Update the [decision log](./decisions.md) | Engine, asset approach, and AI workflow are selected |
| Prepare the first build | Specify one playable milestone | Acceptance criteria, run/export steps, and playtest questions are written |

Game coding begins when these decisions are ready and the project owner chooses to proceed. Implementation and asset trials [E02 and E03](./experiments.md) remain deferred.
